---
description: Processus de Closing et Revue de Lead (Audit, Offres, Contrat)
---

Ce workflow guide l'expert dans l'utilisation de la nouvelle interface de revue pour transformer un lead en client signé.

### 1. Préparation de la Consultation (Onglet Notes)
- Consulter le bloc **Questions Clés** généré par l'IA avant l'appel.
- Utiliser le **Live Assistant** pendant l'échange pour noter les besoins, budgets et objections.
- Cliquer sur `Synchroniser Audit` pour injecter ces notes dans l'intelligence du dossier.

### 2. Ingénierie de l'Audit (Onglet Audit)
- Vérifier les blocs de diagnostic générés.
- Utiliser le mode **Éditeur** pour affiner les conclusions.
- Basculer en mode **Aperçu** pour valider le rendu du livret PDF.
- Cliquer sur `Générer PDF` pour créer la version finale.

### 3. Structuration des Offres (Onglet Propositions)
- Vérifier les options MTA (Multiple Tiered Architecture).
- Utiliser l'**IA Booster** si les tarifs ou les accroches doivent être ajustés stratégiquement.
- Utiliser le bouton `Générer Devis` pour chaque option si nécessaire.
- Cliquer sur `Envoyer Offres` pour déclencher le mail transactionnel au client.

### 4. Sécurisation Contractuelle (Onglet Contrat)
- Relire le résumé des clauses généré automatiquement.
- Utiliser le mode **Aperçu** pour voir le contrat en format "Document Premium" (Paper-style).
- Si des clauses doivent être modifiées, utiliser l'**IA Booster : Contrat**.
- Cliquer sur `Envoyer Signature` pour finaliser le closing via le partenaire de signature électronique.

### 5. Lancement de la Mission (Onglet Kickoff)
- Une fois le contrat signé, le deal passe en "Gagné".
- Activer l'onboarding via le bouton `Lancer l'Onboarding Client`.
- Partager le lien du **Formulaire de Kickoff** pour collecter les accès techniques.
